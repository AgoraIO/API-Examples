# Project Routing Rules

This project is `APIExample-Compose`, using `full-sdk` with Jetpack Compose UI.

## When to Use This Project

- Requires Compose UI or porting an existing case → this project
- Involves video / screen sharing / beauty / extensions (non-Compose UI) → use `APIExample/`
- Audio-only scenarios → use `APIExample-Audio/`

## Hard Constraints

- Do NOT share source files with other sub-projects
- After entering the project, read `AGENTS.md` and `ARCHITECTURE.md` first
- The Skills directory (`.kiro/skills/`) contains standardized workflows — use them first
